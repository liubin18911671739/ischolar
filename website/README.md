# iScholar 科研与教学培训工作台

面向教师的中文响应式教学资源门户。提供 16 次课的日历、科研与教学专题、15 份可复制下载的模板，以及浏览器本地的课程进度、笔记和来源许可记录。

网站是培训方案与学习工具，不代表已获任何院校官方授权，不包含学校内部资料，不调用校内或外部模型 API。

## 运行

使用 Node.js 22（推荐，`.nvmrc` 已配置）或兼容的 Node.js 24。首次安装：

```bash
cd website
npm install
npm run dev
```

访问 http://localhost:3000。已有锁文件的可复现安装使用 `npm ci`。

生产运行：

```bash
npm run build
npm run start
```

无需环境变量、API 密钥、数据库、账号或认证服务。外部链接只作为参考入口，不自动请求外部内容；使用系统字体，不加载远程字体、分析统计或追踪脚本。

## 课程口径

以已确认的 16 次课日历为准，8 周 × 每周 2 次 × 每次 2 小时 = 32 小时。

| 模块 | 课次 | 小时 |
| --- | --- | ---: |
| 科研 | 01–09 | 18 |
| 教学 | 10–15 | 12 |
| 办公综合 | 16 | 2 |

| 专题 | 课次 | 小时 |
| --- | --- | ---: |
| 科研智能体与论文 | 01–06 | 12 |
| 生态语料库 | 07–09 | 6 |
| 教学内容生产 | 10–13 | 8 |
| 图像化 PPT | 14–15 | 4 |
| 办公与综合 | 16 | 2 |

早期提示词中的 `8/6/8/6/4h` 与课次日历不一致，已经按用户确认统一为 `12/6/8/4/2h`。所有汇总从课程数据计算，不单独维护另一套总数。

## 本地记录

- 进度、笔记和来源登记使用 `localStorage`，键名 `ischolar-workbench:v1`。
- 课程页笔记即时保存，刷新后恢复；课程间切换共享进度。
- 导出 JSON 包含版本、完成课次、笔记、来源记录与时间戳；没有导入功能。
- 无法识别的存储数据会停止覆盖，导出时包含原始备份字段。
- 存储被禁用或空间不足时，提示仅保留当前会话，并允许直接导出。
- 清除仅删除本站这个键；不会清空浏览器中其他网站或应用的数据。
- 浏览器记录不等于安全存储，不应填写敏感或涉密信息。更换浏览器或清理站点数据前请导出。

## 检查

```bash
npm run check              # ESLint + TypeScript + 内容一致性
npm run build              # 生产构建与静态预渲染
npx playwright install chromium  # 首次运行浏览器测试需要
npm run test:e2e           # 使用 3107 端口自动启动生产服务
```

浏览器测试覆盖桌面、手机，以及关键页面的平板宽度；包括本地数据异常和存储禁用、下载内容、复制、筛选、搜索、打印、404 和键盘导航。测试报告保存在忽略目录 `playwright-report/`，截图及跟踪文件在 `test-results/`。
