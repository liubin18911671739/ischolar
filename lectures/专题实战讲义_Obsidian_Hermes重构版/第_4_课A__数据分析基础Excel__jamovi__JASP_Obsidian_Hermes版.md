          📈 Step 2：描述统计 — 用 jamovi / JASP 四步出结果
            📖       jamovi 与 JASP 是什么？ 两款完全免费、开源的桌面统计软件，由统计学
                    家专为研究者设计，是国际期刊审稿人最青睐的开源替代方案。

                        jamovi（jamovi.org）—— 界面像 SPSS 但更现代，分析结果实时更
                        新，支持 R 模块扩展

                        JASP（jasp-stats.org）—— 阿姆斯特丹大学开发，贝叶斯统计原生集
                        成，适合前沿文科研究

                    两者通用工作流： 下载安装（约 350 MB） → 双击 Excel/CSV 文件即可打
                    开 → 拖动变量到分析框 → 右侧自动生成 APA 格式表格，可一键复制粘贴
                    到 Word 论文。
                    为什么选它们而不是 SPSS / SPSSAU？ SPSS 单机版年费 ≈ ¥10,000，
                    SPSSAU 数据需上传到云端；而 jamovi / JASP 永久免费、本地运行（数据
                    隐私安全）、文科 95% 需求全覆盖、且可保存 .omv / .jasp 项目文件——下
                    次打开数据 + 分析路径全部复现，方便审稿与答辩。

            🔴       AI 解读结果的铁律：
                        ❌ 不要让 AI 直接编造数据——所有数字必须来自 jamovi/JASP 的真实

                        ✅ AI 擅长的是：把表格翻译成学术段落 + 帮你发现你漏看的信息

          📋 jamovi / JASP 全流程速查卡
            🗂️      问卷分析标准流程（jamovi · 按顺序做）：
                    ① 数据导入 → 问卷星导出 Excel/CSV → jamovi 中 ☰ → Open → 选择文
                    件（变量类型自动识别，可在列头修正为 Nominal / Ordinal / Continuous）
                    ② 信度检验 → Analyses → Factor → Reliability Analysis → 拖入题项 →
                    勾选 Cronbach's α（≥ 0.7 合格）+ "Item if dropped"
                    ③ 效度检验 → Analyses → Factor → Exploratory Factor Analysis → 拖入
                    题项 → 勾选 KMO + Bartlett's test（KMO ≥ 0.7 合格）+ 查看因子载荷
                    ④ 描述统计 → Analyses → Exploration → Descriptives → 拖入变量 → 勾
                    选 Mean / SD / Frequency tables / Histograms
                    ⑤ 差异检验 → Analyses → T-Tests → Independent Samples T-Test（两
                    组）或 Analyses → ANOVA → One-Way ANOVA（多组）
                    ⑥ 相关分析 → Analyses → Regression → Correlation Matrix → 勾选
                    Pearson + p-value + Heatmap 可视化
                    ⑦ 回归分析 → Analyses → Regression → Linear Regression → 设置
                    Dependent Variable + Covariates → 看 β 系数、R²、VIF 共线性诊断
                    💾 保存项目： File → Save 为 .omv 文件，下次打开数据 + 分析路径 + 结
                    果全部复现，便于审稿、答辩、合作
                    📋 结果导出： 右键任意结果表格 → Copy → 直接粘贴到 Word（自动保留
                    APA 格式）
                    ⚠️ 不是每篇论文都要做全部 7 步！ ①②③④ 是必做，⑤⑥⑦ 看你的 RQ 类
                    型选做。
                    💡 JASP 用户： 操作流几乎一致，菜单按钮的英文名也基本相同；JASP 多
                    了"Bayesian"分支，可在每个分析下方一键切换贝叶斯版本（适合小样本研
                    究 + SSCI 加分项）。
