# 第08课｜AI 模块化论文写作与三级润色

> [!abstract] 🎯 本课定位
> 写作不是“一次生成一篇论文”，而是**按模块拼装 + 分层打磨**。AI 最适合做“结构脚手架”和“语言抛光”，最不适合做“核心论点”和“实证结果”。
>
> **学完你将拥有**：一套 IMRaD 模块写作流程、三级润色清单、以及能过查重与 AIGC 检测的成稿策略。

> [!warning] ⚠️ 学术诚信底线
> AI 可以帮你**表达**，不能替你**发现**。所有数据、结果、引文、案例必须真实可核验；使用 AI 辅助应在方法或致谢中如实声明（依目标期刊要求）。

## 🏗️ 二、论文结构：先搭骨架再填肉

### 2.1 IMRaD（国际通用）

| 部分 | 回答什么 | 常见字数（中文期刊） |
| :-- | :-- | :-- |
| Introduction | 为什么做？ | 800–1500 |
| Methods | 怎么做？ | 500–1000 |
| Results | 发现了什么？ | 1000–2000 |
| Discussion | 意味着什么？ | 800–1500 |
| Conclusion | 所以呢？ | 300–500 |
| Abstract | 全文缩影 | 200–300 |

### 2.2 中文学报结构

```text
摘要（中英文）→ 引言 → 研究设计/方法 → 结果与分析 → 讨论 → 结论与建议 → 参考文献
```

### 2.3 模块化写作的核心思路

> [!info] 不要把“写论文”当成一个任务
> 把它拆成 8 个独立任务：摘要、引言、文献综述、方法、结果、讨论、结论、投稿信。每个任务单独对话、单独验收。**一次只让 AI 做一件事**，质量会高一个档次。

| 模块 | AI 适合做什么 | AI 不能做什么 |
| :-- | :-- | :-- |
| 摘要 | 压缩你给的成稿 | 编造未做的发现 |
| 引言 | CARS 结构、衔接句 | 判断你的研究是否真有 Gap |
| 方法 | 规范化表述、补漏项 | 编造样本量与工具版本 |
| 结果 | 把表格转成文字 | 生成你没跑出的数据 |
| 讨论 | 对比文献、列局限 | 替你判断理论贡献 |
| 结论 | 收束、提建议 | 夸大政策意义 |

## 📌 三、CARS 引言模型

### 3.1 三步结构

```text
Move 1 建立领地：这个领域重要，已有研究做了什么
    ↓
Move 2 发现缝隙：然而，现有研究忽略了什么
    ↓
Move 3 占领空间：因此，本研究做什么、怎么做、贡献在哪
```

### 3.2 示例

```markdown
【Move 1】
近年来，生成式人工智能在高校写作教学中的应用快速扩展（张三，2023；李四，2024）。
已有研究表明，AI 反馈能够提升修改效率（Wang et al., 2023），
并在语法层面显著降低错误率（Li, 2024）。

【Move 2】
然而，现有研究多集中于英语母语学习者，对中文语境下外语教师的
"反馈采纳"过程关注不足；同时，多数研究报告了短期效果，
缺乏对教师核验行为的追踪。

【Move 3】
因此，本研究以北京 4 所高校的 32 名外语教师为对象，
采用课堂观察与深度访谈相结合的混合方法，
考察教师在采纳 AI 反馈时的核验策略及其影响因素。
```

### 3.3 提示词模板

```text
请按 CARS 模型为以下研究写一段 800 字引言。

研究主题：[...]
已有研究：[3–5 条，含作者年份与核心发现]
研究空白：[...]
本研究的方法与对象：[...]
核心贡献：[...]

要求：
1. Move 1 引用我提供的文献，不得新增文献；
2. Move 2 明确指出空白，语气克制，不用"填补空白"这类大词；
3. Move 3 交代方法、对象与边界；
4. 每一处引用用 [@citationkey] 占位，便于我回填；
5. 不要写"具有重大理论意义"这类空话。
```

## ✍️ 四、分模块写作实操

### 4.1 摘要（中英双语）

```text
请基于以下成稿，写 250 字中文摘要 + 200 词英文摘要。

结构要求（中文）：背景 1 句 → 问题 1 句 → 方法 2 句 → 结果 2 句（含关键数据）→ 结论 1 句。
英文：对应翻译，符合 SSCI 期刊习惯，避免中式英语。

硬性约束：
- 只使用我提供的数字，不得新增或估算；
- 不出现"显著提升"除非我提供了统计结果；
- 关键词 5 个，含 1 个方法论词。

成稿：
[粘贴结果与结论部分]
```

### 4.2 方法部分

```text
请把以下研究过程整理成规范的方法部分（约 800 字），
按「研究对象—研究工具—数据收集—数据分析—伦理声明」五段组织。

已知信息：
- 对象：北京 4 所高校外语教师 32 人（教龄 3–18 年）
- 工具：课堂观察量表 + 半结构化访谈提纲
- 收集：2026 年 3–6 月，每人 2 次观察 + 1 次访谈
- 分析：访谈转写后用 Taguette 编码，双人编码一致性 Cohen's κ = 0.81
- 伦理：知情同意、匿名化、可随时退出

要求：不得编造工具信效度、样本流失率等我未提供的信息；
缺失处用「[待补：…]」标注。
```

### 4.3 结果部分（把表变成文字）

```text
以下是我的统计结果表：[粘贴]
请写成 400 字的结果叙述。

要求：
1. 先报描述统计，再报推断统计；
2. 每个统计量保留两位小数，格式：t(30) = 2.41, p = .021, d = 0.86；
3. 只描述差异，不做因果解释（解释留给讨论）；
4. 不得新增表中没有的变量或数值。
```

### 4.4 讨论部分

```text
请基于我的结果与以下 5 篇文献，写 900 字讨论。

结构：主要发现复述（1 段）→ 与文献对话（2 段，共识/分歧）→ 理论贡献（1 段）→ 实践启示（1 段）→ 局限（1 段）。

约束：
- 与文献对话时，必须指明"与谁一致/不一致/部分一致"；
- 局限必须具体（样本、方法、时间），不许写"样本量有限"这类套话；
- 不得声称因果，除非我的设计支持。
```

## 🪄 五、三级润色：语言 → 结构 → 逻辑

> [!info] 为什么必须分三级
> 一次性让 AI "润色全文"，它会同时改语言、改结构、改观点——最后你认不出哪句是自己的。分级处理，每级只做一件事。

### 5.1 第一级：语言润色（不改意思）

```text
请只做语言层面的修改：
- 修正语法、搭配、标点；
- 统一术语（全文统一用"生成式人工智能"，不用"生成式 AI"混用）；
- 拆分过长句，压缩冗余表达。

禁止：改变论点、增删论据、调整段落顺序。
输出格式：修改后全文 + 修改说明表（原句 | 改后 | 修改理由）。
```

### 5.2 第二级：结构润色（不改证据）

```text
请只做结构层面的建议：
1. 每段是否有明确主题句？
2. 段落之间的逻辑连接是否成立（因果/并列/转折）？
3. 是否存在重复论述或前后矛盾？
4. 章节长度是否失衡？

输出：问题清单 + 建议调整方案，不要直接改写全文。
```

### 5.3 第三级：逻辑与论证（需人工确认）

```text
请以审稿人视角审查以下章节：
1. 核心论点是否清晰？是否被证据支持？
2. 是否存在"以例代证"（用一个案例推全体）？
3. 因果表述是否超出设计（横断面说因果）？
4. 反例是否被忽略？

输出：逐条问题 + 严重程度（高/中/低）+ 建议处理方式。
不要替我改写，我要自己判断。
```

### 5.4 去 AI 腔（Humanizer）

AI 生成的文本有几个典型特征，需要主动清除：

| AI 腔特征 | 表现 | 修改方向 |
| :-- | :-- | :-- |
| 三段式排比 | "不仅……而且……更重要的是……" | 删掉一层，留最实的 |
| 空泛评价 | "具有重要的理论意义和实践价值" | 换成具体的机制或对象 |
| 过度连接词 | "综上所述""值得注意的是" | 直接说事 |
| 名词化堆砌 | "进行了一个关于……的探讨" | 改成动词句 |
| 对称结构 | "既……又……" 反复出现 | 打破对称 |
| 无主语长句 | "通过分析可以发现……" | 补出"谁"分析了什么 |

> [!tip] 一个有效的自检方法
> 把段落读出声。**你在组会上不会这么说的话，就不要写进论文。**

### 6.1 五个工具的分工

| 工具 | 最强项 | 弱项 | 课程用法 |
| :-- | :-- | :-- | :-- |

| **Grammarly** | 语法、清晰度、语气 | 学术术语误判 | 全篇英文基础检查 |

### 6.2 推荐流水线

```text
中文初稿
  → 秘塔写作猫（错别字/语病）
  → 人工三级润色（语言→结构→逻辑）
  → PaperPass 查重 + AIGC 检测
  → 人工降重（改写而非同义词替换）
  → 定稿

英文初稿
  → Grammarly（基础语法）
  → Writefull（学术搭配）
  → Paperpal（学术风格 + 引用）
  → 人工通读（确保论点未被改）
```

> [!warning] 三个必须人工复核的点
> 1. **QuillBot 改写后，原意是否还在**（尤其否定句与限定词）。
> 2. **Paperpal 的引用建议**是否真的对应你引用的文献。
> 3. **降 AIGC 后，专业术语是否被替换错**（"语料库"被改成"数据库"是灾难）。

## 🔍 七、查重与 AIGC 检测

### 7.1 PaperPass 免费版能做什么

```text
1. 打开 https://www.paperpass.com/upload
2. 选择「免费版（满血版查重 + AIGC 检测）」
3. 填写标题、作者 → 上传 .docx
4. 等待报告：总相似度、分段相似来源、AIGC 疑似段落
```

> [!info] 免费版限制（以官网当期说明为准）
> 仅支持中文，0 元/千字，每天 5 篇。英文或大篇幅稿件需选付费版或其他工具。

### 7.2 查重报告怎么读

| 指标 | 含义 | 处理建议 |
| :-- | :-- | :-- |
| 总相似度 | 与比对库重合比例 | 中文核心期刊通常要求 < 15%（以期刊为准） |
| 单篇重复 | 与某一文献高度重合 | 必须改写或规范引用 |
| 连续 13 字重复 | 经典判定规则 | 改写句式，不是换同义词 |
| AIGC 疑似 | 模型生成特征 | 增补具体数据、案例、个人判断 |

### 7.3 降重的正确与错误做法

| ✅ 正确 | ❌ 错误 |
| :-- | :-- |
| 改变论证顺序与句式结构 | 同义词替换（"提升"→"提高"） |
| 加入自己的数据与案例 | 加"的""了"凑字数 |
| 把长句拆成短句并重组逻辑 | 用翻译软件来回翻 |
| 规范引用并标明出处 | 删除引用只留观点 |

> [!warning] 关于"降 AIGC"
> 工具能把检测分数降下来，但**降不掉内容空洞**。审稿人真正反感的是"没有信息量的流畅"。解决办法只有一个：**加具体的材料、数据、例子和个人判断。**

## ❓ 九、常见问题

> [!question] Q1：AI 写的句子查重会高吗？
> 不会因"AI 生成"而查重高（查重比对的是已发表文本），但 AIGC 检测会标记。真正的问题是内容空。

> [!question] Q2：英文论文用 Grammarly 够吗？
> 基础语法够，学术风格不够。建议 Grammarly → Writefull → Paperpal 三步，最后人工通读。

> [!question] Q3：QuillBot 改写后被导师说"意思变了"？
> 典型问题。改写前先锁定"不可变部分"（术语、数据、限定词、否定），只允许它改句式和连接。

> [!question] Q4：中文期刊要求 AI 使用声明吗？
> 越来越多期刊要求。常见写法：在方法或致谢中说明"本文使用 XX 工具辅助语言润色，研究设计、数据分析与结论由作者独立完成"。

> [!question] Q5：查重率多少算安全？
> 没有统一标准。CSSCI 期刊常见要求 < 10%–15%，学位论文更严。**以目标期刊/学校规定为准**，不要用"别人的标准"。

> [!question] Q6：能让 AI 直接写一整章吗？
> 能，但你会花更多时间改。更高效的是：**你给结构和材料，它给表达**。
