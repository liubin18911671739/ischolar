# 第04课｜AI 辅助文献检索与综述

> [!abstract] 🎯 本课定位
> 这是整套课程里**最容易被 AI 坑**的一课。模型能一秒钟编出 10 条格式完美的假文献，而你可能要花三个月才发现。
>
> **本课的真正目标**：不是“让 AI 帮你写综述”，而是**建立一条“检索 → 获取全文 → 管理题录 → 结构化摘要 → 综合写作 → 逐条回源”的可核验流水线**。

> [!warning] ⚠️ 学术红线
> **任何一条引用，没有在知网 / 原文数据库看到过题名、作者、年份、页码，就不得写入论文。**
> AI 生成的文献列表默认全部视为“待核验”，包括看起来最像真的那些。

## 📚 二、中文文献检索

### 2.1 平台分工

| 平台 | 强项 | 短板 | 课程用法 |
| :-- | :-- | :-- | :-- |
| 知网 | 收录最全、CSSCI 筛选、引文网络 | 需机构订阅，导出有额度限制 | **主线**：高级检索 + Refworks 导出 |
| 万方 | 学位论文、会议论文 | 期刊覆盖略弱 | 补学位论文 |
| 维普 | 中文期刊 | 界面旧 | 补漏 |
| 百度学术 | 免费、聚合 | 元数据偶有错 | 快速摸底、找 DOI |

### 2.2 知网高级检索四步

```text
1. cnki.net → 高级检索
2. 条件设置：
   主题 = ("生成式人工智能" + "大语言模型") * ("学术写作" + "论文写作")
   时间 = 2020—2026
   来源类别 = CSSCI / 北大核心
3. 结果排序：先按「被引」找高影响力，再按「发表时间」看最新进展
4. 勾选 10–20 篇 → 导出/参考文献 → Refworks → 保存 .txt
```

> [!tip] 检索技巧
> - 用**主题**而不是**关键词**（覆盖面更广）。
> - 用**基金**筛选（国家社科、教育部项目）快速定位高质量研究。
> - 用**被引**排序找奠基文献，用**时间**排序找最新争议。
> - 记录每次检索的**检索式与命中数**，写方法部分要用。

### 2.3 AI 辅助扩展检索词

```text
我正在研究「[研究主题]」，请帮我扩展学术检索词。

要求：
1. 5 个中文同义词/近义词
2. 3 组英文对应检索词（含近义与上下位）
3. 2 个上位概念、2 个下位概念
4. 给出可直接粘贴到知网高级检索的布尔表达式
5. 标注哪些词属于「政策话语」而非「学术概念」
```

> [!warning] 扩展词要人工筛
> 模型常把“AI 写作”扩展到“自动作文评分”这类**不同构念**的词。扩展后先用知网试检，看命中文献是否真的相关。

## 🌍 三、英文文献检索与合法获取全文

### 3.1 平台选择

| 平台 | 适合做什么 | 全文可得性 |
| :-- | :-- | :-- |
| Semantic Scholar | AI 摘要（TLDR）、引用网络、相关推荐 | 部分有 PDF 链接 |
| OpenAlex | 批量元数据、机构/主题分析 | 提供 OA 链接 |
| CORE | **直接下全文**（4.5 亿篇） | 高 |
| PMC | 医学、公共卫生全文 | 高 |
| Unpaywall 插件 | 在任意出版商页面找合法免费版 | 约一半论文有绿色标签 |

### 3.2 Unpaywall：一键找合法免费全文

```text
1. 打开 https://unpaywall.org → Install → 选择 Chrome / Edge / Firefox
2. 安装后浏览任意论文页面（如 ScienceDirect、Springer、Taylor & Francis）
3. 页面右侧出现「绿色解锁标签」→ 点击 → 跳转合法免费 PDF
4. 灰色标签 = 未找到免费版 → 改用 CORE / PMC / 馆际互借
```

> [!info] 为什么强调“合法”
> Unpaywall 只索引**作者自存档、机构知识库、OA 期刊**等合法版本，不提供盗版全文。这既保护你也保护学校。

### 3.3 CORE 与 PMC

```text
CORE：https://core.ac.uk → 输入标题/DOI → 结果页 Download PDF
PMC：https://pmc.ncbi.nlm.nih.gov → 输入 PMID/标题 → Full text / PDF
```

### 3.4 英文检索式示例

```text
("generative AI" OR "large language model" OR "LLM")
AND ("academic writing" OR "scholarly writing" OR "research writing")
AND ("higher education" OR "university" OR "faculty")
```

> [!tip] 用 AI 做检索策略，而不是让 AI 给文献
> 让模型帮你**写检索式、拆概念、找同义词**是安全的；让它**列出 20 篇具体文献**几乎必然掺假。

## 🗃️ 四、Zotero 7 + Better BibTeX + Obsidian

### 4.1 Zotero 7 安装与配置

```text
1. https://www.zotero.org/download → 下载 Zotero 7（桌面版）
2. 同时安装 Zotero Connector（浏览器插件）
3. 注册免费账号 → 设置 → 同步 → 登录（300MB 免费空间，题录足够）
4. 设置 → 通用 → 语言：简体中文
```

### 4.2 导入知网 Refworks 文件

```text
Zotero → 文件 → 导入 → 从文件导入 → 选择 .txt（Refworks 格式）
→ 选择放入「新建分类」→ 完成
```

### 4.3 Better BibTeX 配置

```text
1. 下载 .xpi：https://retorque.re/zotero-better-bibtex/
2. Zotero → 工具 → 插件 → 齿轮 → Install Plugin From File → 选择 .xpi
3. 设置 → Better BibTeX → Citation key formula：
   auth.lower + year + shorttitle(3,3).lower
   例：zhangsan2024aigc
4. 右键分类 → Export Collection → 格式选 Better BibTeX → 勾选「Keep updated」→ 导出到 Vault
```

> [!tip] 为什么要稳定的 citation key
> 写作时用 `[@zhangsan2024aigc]` 占位，最后用 Pandoc 或 Zotero 一键生成参考文献。**键名稳定 = 换期刊格式不用重排**。

### 4.4 Obsidian 文献矩阵

1. 安装 Obsidian 插件 `Zotero Integration`。
2. 配置 Zotero 数据库路径（`~/Zotero/zotero.sqlite`）或 Better BibTeX JSON 导出。
3. 在 `02-文献库/` 新建笔记，插入 Zotero 条目，自动生成 frontmatter。
4. 用 Dataview 汇总成矩阵：

```dataview
TABLE year AS 年份, venue AS 期刊, method AS 方法, status AS 状态
FROM "02-文献库"
WHERE type = "literature-note"
SORT year DESC
```

> [!example] 文献矩阵长什么样
> | 作者(年) | 方法 | 样本/语料 | 核心发现 | 局限 | 与我的关系 |
> | :-- | :-- | :-- | :-- | :-- | :-- |
> | 张三(2024) | 问卷 | 高校教师 n=210 | AI 使用强度正向影响写作效率 | 自评数据 | 可作引言背景 |
> | Wang(2023) | 准实验 | 本科生 n=86 | AI 反馈提升修改质量 | 单校 | 方法可借鉴 |

## 🔍 五、AntConc：把语料变成可引用的证据

> [!example] 视频 `10` 演示的完整流程
> 下载 4.4.2 → `File → Open File(s)` 导入语料 → `KWIC` 看索引行 → `Plot` 看分布 → `Cluster` 看高频词簇 → `N-Gram` 看多词序列 → `Collocate` 看搭配 → `Wordcloud` 出图 → `ChatAI`（可选）做辅助解读。

### 5.1 适用场景

| 研究问题 | AntConc 功能 | 产出 |
| :-- | :-- | :-- |
| 某词在不同语料中的使用差异 | KWIC + 频次 | 索引行摘录 |
| 话语的固定搭配 | Collocate | 搭配强度表 |
| 主题词分布 | Keyword + Wordcloud | 主题词云 |
| 词簇/套语 | Cluster / N-Gram | 高频词簇表 |

### 5.2 三条使用纪律

1. **语料来源必须可追溯**：每个文本记 URL、采集日期、许可状态。
2. **分词规则写进方法**：中文分词工具、停用词表、是否保留标点。
3. **索引行不能当结论**：KWIC 是证据片段，需要人工读上下文再解释。

## ✍️ 六、综述写作：从矩阵到段落

### 6.1 漏斗结构（中文期刊常用）

```text
宏观背景（领域现状）
    ↓
主题梳理（2–3 个子主题，每个子主题：共识 → 分歧 → 不足）
    ↓
争议与空白（学界未解决什么）
    ↓
本研究定位（我填补哪一块）
```

### 6.2 OCAR 结构（英文期刊常用）

| 步骤 | 含义 |
| :-- | :-- |
| Overview | 概述领域现状 |
| Contributions | 关键文献的贡献 |
| Arguments | 争议与矛盾 |
| Research Gap | 空白与本研究定位 |

### 6.3 提示词模板（严格版）

```text
你是一位 [学科] 领域的资深研究者。请基于我提供的文献卡片写一段 300–400 字的文献综述。

硬性要求：
1. 只使用我提供的文献，不得引入任何新文献；
2. 每一句带引用的话，引用键必须来自我给的列表；
3. 采用「综合」而非「罗列」：同一段内比较 2 篇以上文献的异同；
4. 明确写出共识、分歧与不足；
5. 任何我未提供的信息，用「[待补证据]」标注，不要自行补全；
6. 输出后附一张「引用核对表」：引用键 | 我提供的原文依据 | 是否可直接使用。

文献卡片：
[粘贴 5–8 条]
```

### 6.4 引用核对表（必做）

| 引用键 | 题名/作者/年份是否核对 | 页码是否核对 | 结论是否被原文支持 | 可用性 |
| :-- | :--: | :--: | :--: | :-- |
| zhangsan2024aigc | ✅ | ✅ p.12 | ✅ | 可直接引用 |
| wang2023feedback | ✅ | ❌ 待查 | ⚠️ 原文献只支持部分 | 改写表述 |

> [!warning] 三种最常见的“看起来没问题”的错误
> 1. **张冠李戴**：把 A 的发现写成 B 的。
> 2. **过度概括**：原文献说“在单校样本中”，综述写成“普遍表明”。
> 3. **时间错位**：引用了 2024 年文献来支持 2020 年的观点。

## ❓ 八、常见问题

> [!question] Q1：AI 给的文献看起来特别真，怎么快速判断？
> 三步：①复制题名到知网/百度学术搜，搜不到基本是假的；②查 DOI，用 `doi.org/xxx` 能否打开；③看期刊是否真实存在。**三步里有一步不过，就不用。**

> [!question] Q2：Unpaywall 显示灰色，还有别的合法途径吗？
> 有：CORE、PMC、作者个人主页、机构知识库、ResearchGate 作者自存档、图书馆馆际互借、直接邮件问作者要。**不要用 Sci-Hub。**

> [!question] Q3：Zotero 免费空间够吗？
> 300MB 只存题录和笔记完全够；PDF 建议用「链接文件」方式存在本地或坚果云 WebDAV。

> [!question] Q4：中文文献能直接导出 BibTeX 吗？
> 知网导出 Refworks 后由 Zotero 转换即可。注意中文作者名可能变成拼音，需人工检查。

> [!question] Q5：综述必须用 AI 写吗？
> 不必。AI 适合做**结构化整理**（矩阵、分类、找共性），**学术判断**（哪些争议重要、哪条线索值得追）必须你自己做。
